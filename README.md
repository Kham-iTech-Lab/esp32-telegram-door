# ESP32 Telegram Door Alert — ประตูเปิดปุ๊บ มือถือเด้งปั๊บ

โค้ดประกอบคลิป **"ESP32 ส่งแจ้งเตือนประตูเปิดเข้า Telegram"**
ติดตามได้ที่ TikTok **K iTech Review** · YouTube / Facebook **Kham iTech Lab**

ประตูเปิดเมื่อไร ESP32 ส่งข้อความเข้า Telegram ทันที ใช้ฟรี ไม่ต้องมีเซิร์ฟเวอร์เพิ่ม
(LINE Notify ปิดบริการไปแล้ว เลยใช้บอท Telegram แทน)

## ของที่ต้องใช้

| ชิ้น | ตัวอย่าง |
|---|---|
| บอร์ด ESP32 | ESP32 DevKit / ESP32-S3 / ESP32-C3 |
| เซนเซอร์ประตูแม่เหล็ก (reed switch) | MC-38 (แบบ 2 สาย) |
| สายไฟ + ไฟเลี้ยง 5V | สาย USB / อแดปเตอร์มือถือ |

## การต่อวงจร

```
reed switch (MC-38)
  สายที่ 1 -> GPIO 4
  สายที่ 2 -> GND
```

ใช้ pull-up ในบอร์ด ไม่ต้องมีตัวต้านทานเพิ่ม
ติดตัวสวิตช์ไว้ที่วงกบ ติดแม่เหล็กไว้ที่บานประตู ให้ห่างกันไม่เกิน ~1 ซม. ตอนปิด

## ขั้นตอน

### 1. สร้างบอทกับ BotFather
1. ใน Telegram ค้นหา **@BotFather** แล้วกด Start
2. พิมพ์ `/newbot` ตั้งชื่อบอท และตั้ง username ที่ลงท้ายด้วย `bot`
3. จะได้ **Token** หน้าตาประมาณ `1234567890:AAH...` เก็บไว้

### 2. หาเลขแชท (Chat ID)
1. เปิดแชทกับบอทที่สร้าง แล้วส่งข้อความอะไรก็ได้ 1 ครั้ง
2. เปิดเบราว์เซอร์ ไปที่ `https://api.telegram.org/bot<TOKEN>/getUpdates` (แทน `<TOKEN>` ด้วยรหัสบอท)
3. หา `"chat":{"id":123456789` ตัวเลขนั้นคือ **Chat ID**
   - ถ้าขึ้น `"result":[]` ให้ส่งข้อความหาบอทใหม่แล้วรีเฟรช

### 3. ต่อเซนเซอร์ตามผังด้านบน

### 4. ใส่ค่าในโค้ด แล้วอัปโหลด
1. ติดตั้ง Arduino IDE และ ESP32 board (Boards Manager → esp32 by Espressif)
2. เปิดโฟลเดอร์ `esp32_telegram_door`
3. คัดลอก `secrets.example.h` เป็น **`secrets.h`** แล้วใส่ Wi-Fi, Token, Chat ID
4. เลือกบอร์ด + พอร์ต แล้วกดอัปโหลด
5. เปิด Serial Monitor (115200) จะเห็นสถานะ Wi-Fi และมือถือจะได้ข้อความ "ระบบแจ้งเตือนประตูพร้อมแล้ว"

ไม่ต้องลงไลบรารีเพิ่ม ใช้แค่ไลบรารีที่มากับ ESP32 board

## ตั้งค่าเพิ่ม (ในไฟล์ .ino)

| ค่า | ทำอะไร |
|---|---|
| `DOOR_PIN` | เปลี่ยนขาที่ต่อเซนเซอร์ |
| `NOTIFY_ON_CLOSE` | `true` = แจ้งตอนประตูปิดด้วย |
| `COOLDOWN_MS` | เว้นระยะแจ้งเตือน กันข้อความรัวตอนเปิดปิดถี่ ๆ |

## ⚠️ เก็บรหัสบอทไว้ให้ดี
- ใครได้ Token ไป ก็ส่งข้อความในนามบอทคุณได้
- `secrets.h` ถูกใส่ใน `.gitignore` แล้ว **อย่าอัปไฟล์ที่มีรหัสจริงขึ้น GitHub หรือส่งให้คนอื่น**
- ถ้ารหัสหลุด ไปที่ @BotFather → `/revoke` เพื่อขอรหัสใหม่

## แก้ปัญหา
- **ไม่มีข้อความเข้า**: ดู Serial Monitor ถ้าขึ้น `Telegram HTTP 401` = Token ผิด, `400` = Chat ID ผิด หรือยังไม่ได้ทักบอทก่อน
- **แจ้งกลับด้าน** (ปิดแล้วเด้ง): เซนเซอร์บางรุ่นเป็นแบบปกติเปิด (NO/NC ต่างกัน) ให้สลับเงื่อนไข `opened = (r == LOW)`
- **ต่อ Wi-Fi ไม่ได้**: ESP32 รองรับเฉพาะ Wi-Fi 2.4GHz
